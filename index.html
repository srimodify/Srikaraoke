เกี่ยวกับเว็บไซต์

เว็บไซต์คาราโอเกะออนไลน์นี้เป็นแพลตฟอร์มที่ให้บริการค้นหาและเล่นเพลงคาราโอเกะผ่าน YouTube โดยใช้ YouTube IFrame Player API เพื่อแสดงวิดีโอคาราโอเกะจากช่องต่างๆ บน YouTube

ระบบนี้พัฒนาขึ้นเพื่อความสะดวกในการค้นหาและจัดการเพลงคาราโอเกะ พร้อมฟีเจอร์ต่างๆ เช่น การค้นหาด้วยเสียง การจัดการ Playlist และรีโมทคอนโทรลสำหรับควบคุมการเล่นเพลงจากระยะไกล

ลิขสิทธิ์เพลง

⚠️ ข้อสำคัญเกี่ยวกับลิขสิทธิ์:

  • วิดีโอคาราโอเกะทั้งหมดที่แสดงบนเว็บไซต์นี้เป็นเนื้อหาจาก YouTube
  • เว็บไซต์นี้ ไม่ได้เป็นเจ้าของลิขสิทธิ์ ของเพลงหรือวิดีโอใดๆ
  • ลิขสิทธิ์ของเพลงและวิดีโอเป็นของเจ้าของลิขสิทธิ์ดั้งเดิม (ศิลปิน, ค่ายเพลง, หรือช่อง YouTube ที่อัปโหลด)
  • เว็บไซต์นี้เป็นเพียงแพลตฟอร์มที่ช่วยให้ผู้ใช้ค้นหาและเข้าถึงวิดีโอคาราโอเกะที่เผยแพร่บน YouTube

📋 การใช้งาน:

  • เว็บไซต์นี้ใช้ YouTube IFrame Player API ตามข้อกำหนดและเงื่อนไขของ Google/YouTube
  • วิดีโอทั้งหมดถูกฝัง (embed) จาก YouTube โดยตรง ไม่มีการดาวน์โหลดหรือจัดเก็บวิดีโอบนเซิร์ฟเวอร์ของเว็บไซต์
  • การแสดงผลวิดีโอเป็นไปตามนโยบายและข้อกำหนดของ YouTube
  • หากเจ้าของลิขสิทธิ์ต้องการให้ลบวิดีโอใดๆ กรุณาติดต่อเจ้าของช่อง YouTube ที่อัปโหลดวิดีโอนั้น

โฆษณาจาก YouTube และรายได้

💰 รายได้และยอดวิว:

  • รายได้จากโฆษณา: รายได้ทั้งหมดจากโฆษณาที่แสดงในวิดีโอเป็นของเจ้าของช่อง YouTube ที่อัปโหลดวิดีโอนั้นๆ
  • ยอดวิว: ยอดวิวทั้งหมดจะถูกนับเข้าสู่ช่อง YouTube ต้นฉบับที่อัปโหลดวิดีโอ
  • เว็บไซต์นี้ไม่ได้รับรายได้: เว็บไซต์นี้ไม่ได้รับรายได้จากโฆษณาหรือยอดวิวใดๆ ทั้งสิ้น
  • รายได้ทั้งหมดเป็นไปตามเงื่อนไขและนโยบายของ YouTube Partner Program

📺 การแสดงโฆษณา:

  • โฆษณาที่แสดงในวิดีโอเป็นไปตามการตั้งค่าของเจ้าของช่อง YouTube
  • YouTube จะแสดงโฆษณาตามนโยบายและเงื่อนไขของ YouTube Partner Program
  • เว็บไซต์นี้ไม่สามารถควบคุมหรือจัดการโฆษณาที่แสดงในวิดีโอได้
  • การแสดงโฆษณาขึ้นอยู่กับการตั้งค่าของเจ้าของช่องและนโยบายของ YouTube

📌 สรุป:

เว็บไซต์นี้เป็นเพียงแพลตฟอร์มที่ช่วยให้ผู้ใช้ค้นหาและเข้าถึงวิดีโอคาราโอเกะบน YouTube โดยไม่ได้รับรายได้ใดๆ จากโฆษณาหรือยอดวิว รายได้และยอดวิวทั้งหมดเป็นของเจ้าของช่อง YouTube ที่อัปโหลดวิดีโอต้นฉบับ

ข้อกำหนดการใช้งาน

  • ผู้ใช้ต้องปฏิบัติตามข้อกำหนดและเงื่อนไขของ YouTube เมื่อใช้งานวิดีโอ
  • ห้ามใช้เว็บไซต์เพื่อวัตถุประสงค์ที่ผิดกฎหมายหรือละเมิดลิขสิทธิ์
  • เว็บไซต์สงวนสิทธิ์ในการเปลี่ยนแปลงหรือหยุดให้บริการได้โดยไม่ต้องแจ้งล่วงหน้า
  • ผู้ใช้ต้องรับผิดชอบต่อการใช้งานเว็บไซต์ของตนเอง
  • หากพบวิดีโอที่ละเมิดลิขสิทธิ์ กรุณาติดต่อเจ้าของช่อง YouTube ที่เกี่ยวข้อง

🎤 ระบบเล่น & ค้นหาเพลง

  • ค้นหาและเล่นเพลงคาราโอเกะจาก YouTube ได้ทันที ไม่ต้องดาวน์โหลดหรือติดตั้งอะไรเพิ่ม
  • ค้นหาได้ทั้งจากจอหลักโดยตรง และจากมือถือผ่านรีโมท พร้อมภาพตัวอย่างย่อ (thumbnail) ของผลการค้นหา — พิมพ์แล้วเห็นผลค้นหาจากไฟล์ในเครื่องแบบเรียลไทม์ทันที
  • เล่นเพลงจากไฟล์ในเครื่องได้ด้วย นอกเหนือจาก YouTube — เลือกโฟลเดอร์เพลงหลักแล้วระบบค้นเพลงในโฟลเดอร์ย่อยให้อัตโนมัติ ผลค้นหามีป้ายบอกแหล่งที่มา (🌐 YouTube / 💻 อุปกรณ์) ให้แยกชัดเจนทั้งในผลค้นหาและในคิว
  • ปุ่ม "เพลงแนะนำ" ให้แตะค้นหาได้ทันทีโดยไม่ต้องพิมพ์ และปุ่ม "ยอดนิยม" ดึงเพลงฮิตล่าสุดจาก YouTube มาให้เลือกเพิ่มเข้าคิวได้เลย
  • วางลิงก์ YouTube โดยตรงเพื่อเพิ่มเพลงได้ แม้ไม่ได้ตั้งค่า API Key

📋 การจัดการคิวเพลง

  • เพิ่ม ลบ แทรกเล่นถัดไป และจัดเรียงลำดับคิวได้ (ลากวางหรือปุ่ม ▲▼)
  • เล่นเพลงถัดไปในคิวอัตโนมัติ และลบเพลงที่เล่นจบออกจากคิวให้เองทันที
  • โหมด "คิวคนร้อง" แบ่งคิวเท่าเทียมอัตโนมัติ (คนละ 2 เพลงต่อรอบ) กันคนเดียวจองคิวรวด
  • บันทึก/โหลดเพลย์ลิสต์ และดูประวัติเพลงที่เล่นไปแล้วทั้งหมด พร้อมเหตุผลที่เปลี่ยนเพลงและเวลาที่ผ่านมา
  • สำรอง/กู้คืนข้อมูลทั้งหมด (เพลย์ลิสต์ + ประวัติ) เป็นไฟล์ .json เดียว
  • ปุ่ม "เริ่มงานใหม่" ล้างคิว/คะแนน/ประวัติในคลิกเดียว เตรียมพร้อมสำหรับงานครั้งถัดไป

📱 รีโมทมือถือผ่าน QR Code

  • สแกน QR เพื่อควบคุมจากมือถือได้พร้อมกันหลายเครื่อง เชื่อมต่อกลับมาอัตโนมัติเมื่อเปิดจอมือถือกลับมาโดยไม่ต้องสแกนใหม่
  • แยกสิทธิ์ 3 ระดับ: จอหลัก, รีโมทแอดมิน (คุมได้ทุกอย่าง), รีโมทผู้ใช้ทั่วไป (เพิ่ม/ลบเพลง ปรับจังหวะ-เสียง)
  • ล็อกห้องด้วยรหัส PIN ได้ (ทางเลือก) กันคนแปลกหน้าเข้ามาคุมคิว และจัดการ/ตัดการเชื่อมต่ออุปกรณ์ที่เชื่อมอยู่ได้จากจอหลัก

🖥️ ระบบจอที่ 2 (ทางเลือก)

  • เปิดใช้งานได้จากเมนูตั้งค่า — จอแสดงผลเสริมไร้สาย เชื่อมต่อแยกจากจอหลัก (ไม่กระทบจอหลักเลย)
  • แสดงวิดีโอเต็มจอ ชื่อเพลงที่กำลังเล่น เพลงถัดไป (กระพริบก่อนเพลงจบ 15 วินาที) และคะแนนร้องเพลง เหมาะสำหรับวางให้นักร้อง/ผู้ชมดูแยกจากจอควบคุม
  • เลือกได้ว่าจะให้เสียงออกจากจอหลักหรือจอที่ 2 สลับได้ตลอดเวลาระหว่างงาน

🎚️ ควบคุมการเล่น

  • ปรับจังหวะ (Tempo) และระดับเสียง/ปิดเสียงได้ทั้งจากจอหลักและรีโมท
  • ระบบให้คะแนนร้องเพลงแบบสุ่มหลังเพลงจบ พร้อมกระดานผู้นำ 5 อันดับ แสดงทั้งจอหลัก มือถือทุกเครื่อง และจอที่ 2
  • แสดงคอร์ดกีตาร์ของเพลงที่กำลังเล่นได้ — พิมพ์คอร์ดเตรียมไว้เอง (แบบง่ายหรือแบบระบุเวลาละเอียด) ผูกกับเพลงนั้นไว้ถาวร เล่นซ้ำครั้งไหนก็ขึ้นให้อัตโนมัติ ใช้ได้ทั้งเพลงจาก YouTube และไฟล์ในเครื่อง

⚙️ ใช้งานสะดวก

  • ติดตั้งเป็นแอป (PWA) ได้ทั้งจอทีวี กล่องแอนดรอย และมือถือ
  • รองรับภาษาไทยเต็มรูปแบบ ทั้งแนวตั้งและแนวนอน สลับเลย์เอาต์ให้อัตโนมัติตามการหมุนจอ
  • โหมดเต็มจอของแอปเอง (ไม่ใช่แค่ของ YouTube) พร้อมปุ่มลอยซ่อน/แสดงเมนูแบบโปร่งใส ไม่บังจอ
  • สลับธีมมืด/สว่างได้ และเปิดโหมดประหยัดพลังสำหรับจอหลักที่สเปกไม่แรง
  • เมนู Header เลื่อนดูได้บนจอเล็ก/มือถือ กรณีมีปุ่มเยอะจนแสดงไม่หมด
  • นำทางด้วยรีโมททีวี/กล่องแอนดรอยได้ ปุ่มโฟกัสด้วย D-pad รองรับปุ่มสื่อ (เล่น/หยุด/ข้าม)
  • ซ่อน/แสดงแผงคิวเพลงบนจอหลักได้ เพื่อโฟกัสที่วิดีโอเต็มจอ
  • ปุ่ม "ออกจากระบบ" พร้อมป๊อปอัพยืนยันก่อนออก ตัดการเชื่อมต่อรีโมท/จอที่ 2 ทั้งหมดให้เรียบร้อยก่อนปิด

    จอที่ 2

    🖥️ เปิดใช้งานจอที่ 2
    จอแสดงผลเสริม (วิดีโอเต็มจอ + ชื่อเพลง + คะแนน) เชื่อมต่อไร้สายแยกจากจอหลัก

    ไม่มีกล้อง/สแกน QR ไม่ได้? เปิดหน้าจอที่ 2 แล้วพิมพ์ "รหัสห้อง" กับ "PIN" ตัวเดียวกับที่โชว์อยู่ในส่วนรีโมทผู้ใช้ทั่วไปด้านบนได้เลย ไม่ต้องใช้กล้องเลย

    🔊 เสียงออกที่
    ปุ่มปรับเสียงเดิม (จอหลัก+รีโมท) จะไปควบคุมจอที่เลือกไว้นี้แทน อีกจอจะถูกปิดเสียงอัตโนมัติกันเสียงซ้อน

    เพลงจากอุปกรณ์

    เลือกโฟลเดอร์หลักที่เก็บไฟล์เพลง/วิดีโอคาราโอเกะในเครื่องนี้ ระบบจะค้นหาในโฟลเดอร์ย่อยทั้งหมดให้ด้วย เพลงจากอุปกรณ์จะขึ้นแสดงในผลค้นหาปนกับ YouTube โดยมีสัญลักษณ์ 💻 กำกับไว้

    ยังไม่ได้เลือกโฟลเดอร์เพลง

    ⚠️ ต้องเลือกโฟลเดอร์ใหม่ทุกครั้งที่เปิด/รีเฟรชหน้านี้ (เบราว์เซอร์ไม่จำโฟลเดอร์ข้ามเซสชันด้วยเหตุผลด้านความปลอดภัย) เพลงจากอุปกรณ์เล่นได้เฉพาะบนเครื่องที่เลือกโฟลเดอร์ไว้เท่านั้น ใช้งานได้ดีที่สุดบน Chrome/Edge บนคอมพิวเตอร์ — กล่องแอนดรอย/สมาร์ททีวีบางรุ่นอาจไม่รองรับการเลือกโฟลเดอร์
