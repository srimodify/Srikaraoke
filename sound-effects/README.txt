วิธีเพิ่มเสียงเอฟเฟกต์
========================

1. อัปโหลดไฟล์เสียง (.mp3, .wav, .ogg, .m4a, .aac) มาไว้ในโฟลเดอร์นี้ (sound-effects/)

2. เปิดไฟล์ manifest.json ในโฟลเดอร์นี้ แล้วเพิ่มรายการไฟล์ลงในลิสต์ มี 2 แบบให้เลือก:

   แบบง่าย (แสดงเป็นชื่อไฟล์อย่างเดียว ไม่มีไอคอน):
   "เสียงตรบมือ.mp3"

   แบบมีไอคอน/อิโมจิ (แนะนำ — กำหนดหน้าตาปุ่มเองได้):
   { "file": "เสียงตรบมือ.mp3", "icon": "👏", "label": "ปรบมือ" }

   ตัวอย่างไฟล์ manifest.json ที่มีทั้งสองแบบผสมกัน:

   [
     { "file": "เสียงตรบมือ.mp3", "icon": "👏", "label": "ปรบมือ" },
     "เสียงเชียร์.mp3"
   ]

   - "file" ต้องตรงกับชื่อไฟล์จริงทุกตัวอักษร (รวมนามสกุล)
   - "icon" ใส่อิโมจิอะไรก็ได้ 1 ตัว ถ้าไม่ใส่ ปุ่มจะแสดงเป็นชื่อแทน
   - "label" คือชื่อที่จะโชว์บนปุ่ม ถ้าไม่ใส่ จะใช้ชื่อไฟล์ (ตัดนามสกุลออก) แทนอัตโนมัติ
   - คั่นแต่ละรายการด้วยเครื่องหมาย , (คอมมา)
   - ห้ามลืมวงเล็บเหลี่ยม [ ] ครอบทั้งหมด

3. บันทึกไฟล์ แล้วรีเฟรชหน้าจอหลัก — ปุ่มเอฟเฟกต์จะขึ้นให้อัตโนมัติ พร้อมส่งไปอัปเดตที่รีโมท/จอที่ 2 ที่เชื่อมต่ออยู่ให้เองด้วย

ไม่ต้องแก้โค้ดที่ไหนเลย แค่แก้ไฟล์ manifest.json ไฟล์เดียวเท่านั้น
